# PupWiki

Dog care guidance and breed research platform for US dog owners. Covers breeds, health, costs, training, names, and product recommendations.

**Stack:** Astro 4 · Tailwind CSS · TypeScript · Cloudflare Pages · GitHub Actions

**~400 breed pages · 1,415 blog posts · 75 crossbreeds · 5,000 dog names · per-breed cost calculator**
